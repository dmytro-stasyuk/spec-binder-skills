## `implementation-detail` — what, not how

Kind: issue

- Flag: technical mechanisms in steps or titles, such as HTTP verbs and endpoints, SQL, class, method or table
  names, JSON fields, CSS selectors, queues, caches or feature flags. The exception is a spec whose users are
  developers and whose capability *is* that mechanism.
- Flag: UI mechanics where the intent is what matters ("I click the Save button", "I type into the email field", "I
  scroll down"). The step should state the goal ("I save the invoice").
- Flag: implementation choices baked into outcomes ("the cart is updated via a background job").
